## 2026-11-26

## DECISION
- マイページ（ASICS-My-Page）のお気に入り一覧は、ヒストリーサイトと同じリスト標準の「いいね」（LikedByStringId）から、ログインユーザーの ID を含む項目だけを取って表示する: 別のお気に入り保存先を作らず、ハートの付け外しが両ページに反映されるため
- お気に入りの解除は、ヒストリーサイトと同じ Reputation.SetLike（false）を使う: 何度呼んでも同じ結果になり、既に外れている場合のエラーも成功扱いにできる
- ASICS-My-Page の JS/CSS は手書きとして `demo-top/sharepoint-build/` に置く: `build-sharepoint.js` は demo-top 用の2ファイルだけを上書きするので、手書きの My-Page は消えない
- ヘッダー固定は `position:fixed` ＋ SharePoint の内容領域（contentScrollRegion）の位置・幅を JS で測って合わせる: ページ全体ではなく領域内でスクロールするため

## INSIGHT
- SharePoint のヘッダーはスクロールで縮み、内容領域の上端が動く。位置を最初の1回しか測らないと、固定ヘッダーとの間に隙間ができる → スクロール・リサイズのたびと、縮むアニメーション中（約0.8秒）は requestAnimationFrame で測り直す
- ScriptLoader はファイル名でページを決める。ファイル名を変えたら、JS 内のページ判定（PAGE_RE）と SharePoint 側のページ名も揃える必要がある
- 写真の上に重ねるハートは、細い線だけだと埋もれる。白い丸の台＋影＋サイズ拡大で見やすくなる

## PATTERN
- SharePoint の固定ヘッダー: `--hd-top / --hd-left / --hd-right` を JS で内容領域に合わせて設定し、スクロール中は rAF で追従（demo-top の app.sp.js の initHeader、My-Page の fixHeader）
- ログインユーザーのお気に入り取得: `web/currentuser?$select=Id` と `items?$select=…,LikedByStringId` を組み合わせ、`LikedByStringId` に自分の ID が含まれる項目で絞る
